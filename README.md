# skills

Claude Code skills for UI polish and UX quality.

| Skill | What it does |
|---|---|
| `/animate-this-app` | Adds tasteful, industry-standard animations and micro-interactions to any project while keeping its original look and personality, with a strict motion budget so only animations that earn their place ship. Disney's 12 principles for UI, press scale, enter/exit, directional steppers, accordions, springs, rubber-band drag, reduced-motion support. |
| `/check-user-experience` | Audits a UI against all 30 Laws of UX (Fitts, Hick, Jakob, Miller, Doherty, Postel, Gestalt, Peak-End, Zeigarnik…) and reports issues with severity, location and suggested fixes. |

## Install

**Claude Code plugin**
```
/plugin marketplace add aswin-haridas/skills
/plugin install ux-skills@aswin-haridas-skills
```

**skills CLI**
```bash
npx skills add aswin-haridas/skills
```

**Manual:** copy a folder from `skills/` into `~/.claude/skills/`.
